# Post-Compromise Persistence Readiness Checker

A defensive readiness and verification workspace for reviewing common account-level persistence paths after a suspected compromise.

## MVP
- Guided checklist for sessions, recovery methods, app grants, mailbox rules, and role changes
- Synthetic evidence records with status and timestamps
- Prioritized follow-up actions and ownership
- Recheck workflow and incident closure summary

## Scope
MVP uses fixtures and checklists; it does not inspect or change real accounts. See [project brief](docs/PROJECT_BRIEF.md).
